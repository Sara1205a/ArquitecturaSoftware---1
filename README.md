# ArquitecturaSoftware---1
Práctica 1. Diseño sostenible y principios SOLID

DentaCare System - Refactorización y Arquitectura Sostenible
Repositorio correspondiente a la Práctica 1: Diseño Sostenible y Principios SOLID de la materia Arquitectura de Software I. Este proyecto aborda el diagnóstico cuantitativo, la refactorización orientada a principios SOLID y la documentación formal de decisiones arquitectónicas de un módulo legado de gestión de citas odontológicas.

Diagnóstico y Métricas (Fase 1): Identificación de violaciones SOLID (SRP, OCP, LSP, ISP, DIP) y cálculo de métricas iniciales (LCOM96b, $C_e$, $C_a$, Inestabilidad $I$).   Refactorización (Fase 2 y 3): Desacoplamiento de responsabilidades (persistencia, notificaciones y reglas de negocio) mediante Inyección de Dependencias e Interfaces.   Decisiones Arquitectónicas (Fase 4): Documentación formal de los ADRs bajo el estándar ISO/IEC/IEEE 42010:2022
